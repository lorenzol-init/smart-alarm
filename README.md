# Smart Alarm

Smart Alarm calculates the appropriate wake-up time based on the required arrival time, preparation time, weather conditions, and traffic conditions.

## Goals

- Calculate a dynamic wake-up time.
- Account for weather and traffic conditions.
- Run the backend platform on Kubernetes.
- Follow production-oriented development and DevOps practices.
- Use the project as a learning environment for Kubernetes, CI/CD, observability, security, and infrastructure automation.
